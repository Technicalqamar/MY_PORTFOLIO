About

From front-end into full-stack

Where I started, where I've moved to, and how I approach building.

I started out building front-end work — responsive layouts with HTML, CSS and JavaScript, then moving into React for component-driven interfaces. That foundation is still what I build on: clean markup, sensible component structure, and layouts that hold up from a phone to a wide desktop.

What changed is how far I take a project. I've been moving into the back-end so I can own the whole request path instead of stopping at the interface — Express routes and middleware, Mongoose models mapped to MongoDB, and JWT authentication guarding protected endpoints. It means I can take a feature from schema to API to screen without leaving the codebase.

On top of that I work with Next.js for server-rendered React, and use Git, GitHub, Postman and VS Code day to day. I'm currently looking for an internship or junior full-stack role where I can keep building on this, ideally alongside an experienced team.

About

Focused on front-end, built on React

Where I'm coming from, and how I approach building interfaces.

I'm a front-end developer focused on building clean, responsive interfaces with HTML, CSS, JavaScript and React. My current focus is strengthening real-world React development skills — component architecture, routing, and connecting interfaces to services like Firebase.

Rather than studying in isolation, I build practical projects that mirror real product interfaces: dashboards, content platforms, and multi-page sites. Each one is an exercise in structuring components sensibly, keeping layouts responsive across devices, and writing code that's easy to read and extend.

I use Git and GitHub for version control on every project, and lean on Tailwind CSS or Bootstrap depending on what a layout calls for. I'm currently looking for an internship or junior role where I can keep building on this foundation alongside an experienced team.
